# История изменений OxDeck

Все заметные изменения проекта фиксируются в этом файле. Версии следуют правилам [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Изменено

- React-интерфейс переведён на TypeScript (`.tsx`).
- Добавлен Tailwind CSS 4 через официальный Vite-плагин.

## [0.1.0] — 2026-09-03

### Добавлено

- OxDeck — панель быстрого запуска приложений под чёлкой MacBook.
- Показ загрузки CPU, RAM и температуры аккумулятора.
- Файловая полка с переносом файлов и папок из Finder и обратно.
- Сохранение файловой полки между перезапусками.
- React-интерфейс и разработка через Vite.
- Автоматическая сборка macOS-релизов для Apple Silicon и Intel.
