# История изменений OxDeck

Все заметные изменения проекта фиксируются в этом файле. Версии следуют правилам [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [1.6.2] — 2026-10-13

### Исправлено

- Панель ищет монитор по названию, сохранённому в настройках; ID используется только среди подходящих экранов. При переподключении док-станции другой монитор с прежним ID больше не перехватывает панель.
- Добавлены проверки перестановки ID экранов при переподключении док-станции: без выбранного монитора панель остаётся свёрнутой, после его подключения возвращается на него.

## [1.6.1] — 2026-10-12

### Исправлено

- Панель сохраняет выбранный монитор при изменении его ID, разрешения или названия, сворачивается при отключении и автоматически возвращается после подключения.
- После восстановления из Dock или переноса системой панель возвращается на выбранный монитор; настройки стороны, ширины и размера интерфейса сохраняются при смене разрешения.
- Восстановление панели сбрасывает флаг ручного сворачивания, чтобы он не блокировал последующее автоматическое раскрытие.

## [1.6.0] — 2026-09-19

### Добавлено

- Проверка опубликованных стабильных GitHub Releases при запуске, каждые шесть часов и по кнопке в настройках.
- Фоновая загрузка обновления с проверкой SHA-256, сохранением архива между запусками и индикатором готовности на настройках.
- Установка и перезапуск по кнопке без дополнительных подтверждений, с проверкой подписи новой сборки.
- Подпись релизных сборок постоянным самоподписанным сертификатом без платного Apple Developer.

## [1.5.0] — 2026-09-14

### Добавлено

- Редактирование инструкции плитки «Переписать текст» через «Изменить → •••» с сохранением между перезапусками.

### Изменено

- Инструкция по умолчанию не только исправляет ошибки, но и улучшает логику, структуру и абзацы текста; при необходимости использует списки.

## [1.4.1] — 2026-09-14

### Исправлено

- Запуск Codex CLI из Finder: каталог найденного Codex добавляется в PATH дочернего процесса, чтобы обертка CLI могла найти установленный рядом Node.js.
- Сообщения об ошибках переписывания показывают этап сбоя и числовой код завершения CLI.

### Изменено

- Инструкция переписывания заменяет «ё/Ё» на «е/Е» и просит по возможности избегать длинного тире.

## [1.4.0] — 2026-09-14

### Добавлено

- Плитка «Переписать текст»: исправление ошибок и формулировок в тексте из буфера обмена через установленный Codex CLI с сохранением языка, тона и смысла.
- Индикатор обработки, блокировка повторного запуска и краткий статус «Готово». Успешный результат автоматически заменяет буфер; при ошибке или пустом ответе буфер не меняется.
- Отключение MCP-серверов, приложений и плагинов только для запуска этой активности. Текущие модель и авторизация Codex сохраняются, пользовательский конфиг не меняется.

## [0.1.0] — 2026-09-03

### Добавлено

- OxDeck — панель быстрого запуска приложений под чёлкой MacBook.
- Показ загрузки CPU, RAM и температуры аккумулятора.
- Файловая полка с переносом файлов и папок из Finder и обратно.
- Сохранение файловой полки между перезапусками.
- React-интерфейс и разработка через Vite.
- Автоматическая сборка macOS-релизов для Apple Silicon и Intel.
