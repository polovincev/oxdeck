# OxDeck

Персональная программируемая панель от OxLab. Текущий режим для macOS появляется при наведении курсора на верхний центр экрана и визуально раскрывается из чёлки MacBook.

## Требования

- macOS
- Node.js 22.12 или новее
- pnpm

## Установка и запуск

```bash
pnpm install
pnpm dev
```

После запуска панель показывается на несколько секунд. Затем подведите курсор к верхнему центру экрана. Кнопка `×` полностью завершает приложение.

Кнопка `⚙` открывает настройки отображения. В режиме **Компактный** панель раскрывается по наведению на любом экране. В режиме **Рабочая панель** она постоянно занимает левую половину рабочей области выбранного монитора. Выбор сохраняется между запусками; если монитор отключён, OxDeck временно возвращается в компактный режим и автоматически восстанавливает рабочую панель после его подключения.

Раздел **Управление окнами** размещает активное окно в левой или правой половине, правой верхней или нижней четверти либо разворачивает его в пределах рабочей области текущего монитора. OxDeck использует встроенный macOS Accessibility API, поэтому при первом применении команды потребуется разрешить приложению управление в разделе **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.

Файлы и папки можно перетащить из Finder на любую часть открытой панели. Они останутся в исходной папке, а на файловой полке сохранится только ссылка. Перетащите карточку с полки обратно в Finder, чтобы скопировать объект в выбранную папку; обычный клик показывает оригинал, а `×` убирает только карточку.

Команда `pnpm dev` запускает React, TypeScript и Tailwind CSS через Vite. Изменения интерфейса в папке `src` появляются без перезапуска Electron; изменения в `main.cjs` и `preload.cjs` перезапускают приложение автоматически. Для обычного запуска используйте `pnpm start` — перед запуском команда соберёт React-интерфейс.

## Где редактировать

- `main.cjs` — размеры окна, зона наведения и список запускаемых приложений.
- `src/main.tsx` — весь React-интерфейс, кнопки и файловая полка.
- `src/index.html` — точка подключения React.
- `src/styles.css` — Tailwind CSS, специфичные эффекты чёлки и анимация.
- `src/types.d.ts` — типы безопасного Electron-моста.
- `preload.cjs` — безопасный мост между React и Electron.

Чтобы добавить приложение, внесите одинаковый идентификатор в `applications` внутри `main.cjs` и в массив `applications` внутри `src/main.tsx`.

## Сборка готового приложения

```bash
pnpm package
```

Готовый файл появится в `out/OxDeck-darwin-*/OxDeck.app`.

Для создания переносимого ZIP-архива:

```bash
pnpm make
```

Версионированный архив для Apple Silicon появится в `out/releases`. Для Intel используйте `pnpm make:x64`.

## Версии и GitHub Releases

История версий хранится в [`CHANGELOG.md`](CHANGELOG.md). Инструкция по созданию GitHub-репозитория и выпуску релизов находится в [`RELEASING.md`](RELEASING.md). После публикации тега `v*` GitHub Actions автоматически соберёт ZIP-файлы для Apple Silicon и Intel и добавит их на страницу Releases.

Сборка пока не подписана сертификатом Apple. На этом Mac она запускается нормально; при переносе на другой Mac Gatekeeper может попросить дополнительное подтверждение.
