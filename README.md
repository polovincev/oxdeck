# OxDeck

OxDeck — настраиваемая панель для macOS в духе Stream Deck. Она закрепляется на выбранном мониторе, остаётся поверх окон и показывает сетку приложений, команд размещения окон, системных показателей и файловой полки.

## Запуск

### Скачанная сборка

Распакуйте архив из GitHub Releases и перенесите `OxDeck.app` в папку «Программы» (`/Applications`). Сборка пока не подписана сертификатом Apple. Если macOS сообщает, что приложение повреждено, для доверенной сборки выполните в Терминале:

```bash
xattr -dr com.apple.quarantine "/Applications/OxDeck.app"
```

Команда снимает карантин только с OxDeck, но не исправляет подпись приложения. После этого попробуйте открыть `OxDeck.app` снова.

### Из исходников

Требуются macOS, Node.js 22.12+ и pnpm.

```bash
pnpm install
pnpm dev
```

На первом запуске выберите монитор, сторону, ширину и размер интерфейса. Для широких дисплеев без системного DPI-масштабирования OxDeck автоматически увеличивает содержимое и клетки сетки; значение 100%, 125% или 150% можно сохранить отдельно для каждого монитора. За внутренний край панель переключается между 50%, 60%, 70% и 100%. При отключении выбранного монитора OxDeck сворачивается и автоматически возвращается после его подключения.

## Рекомендуемые приложения

Для эффективной работы OxDeck на сенсорном мониторе рекомендуем установить:

- **Touchscreen Gestures** — для работы сенсорного ввода и жестов.
- **BetterDisplay** — для управления яркостью монитора.

## Сетка

Кнопка **Изменить** включает редактор. Нажмите пустую клетку, чтобы добавить:

- любое установленное приложение;
- одну из двенадцати команд размещения окна;
- CPU, RAM, заряд, температуру аккумулятора или свободное место;
- один постоянный файловый буфер размером от 2×2.
- один конструктор команд Kubernetes размером 1×1 или 2×1.
- одну плитку «Переписать текст» размером 1×1.

В редакторе виджеты можно перетаскивать, менять допустимый размер и удалять. Изменения применяются только по кнопке **Сохранить**.

Файлы принимаются только внутри файлового буфера. Клик открывает файл, перетаскивание отдаёт его наружу, а контекстное меню позволяет показать, заменить или убрать ссылку. Оригиналы не копируются и не удаляются.

Команды окон работают с последним активным окном на его текущем мониторе. Монитор самого OxDeck исключён. При первом использовании macOS запросит доступ в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.

## Команды Kubernetes

Добавьте плитку через **Изменить → пустая клетка → Kubernetes → Сохранить**. Новая плитка занимает 1×1; кнопка **↔** в редакторе переключает размер между 1×1 и 2×1, если соседняя клетка свободна. Kubernetes открывается на всю область OxDeck, закрывая меню и виджеты. Кнопка **Назад** или Escape возвращает на дашборд. Разделы **Кластер → Namespace → Поды → Действия** и параметры команды используют крупные плашки для тач-экрана. Списки разбиты на страницы: число плашек подстраивается под размер окна, вертикальной прокрутки нет. Поиск фильтрует списки. Поды показывают состояние, готовность контейнеров и число перезапусков; в низком окне плашки показывают только имена.

Действия готовят команды: список подов, логи (включая непрерывный просмотр и предыдущий запуск контейнера), описание пода, YAML/JSON, вход через sh/bash и port-forward для pod/service. Контейнеры выбираются из выбранного pod, включая init, sidecar и отладочные контейнеры. Для логов есть крупные кнопки периода и количества строк, а также ввод своих значений.

Строка готовой команды и кнопка копирования всегда видны внизу. Предпросмотр обновляется при вводе. **Копировать** помещает её в буфер обмена для самостоятельного запуска в терминале. В каждой команде явно указаны `--context` и `--namespace`; текущий контекст kubeconfig не меняется. Настройки сохраняются локально между запусками. Namespace запоминается для каждого контекста; при смене контекста или namespace имена pod, контейнера и service очищаются.

Нужен установленный `kubectl`: OxDeck ищет его в PATH, `/opt/homebrew/bin`, `/usr/local/bin` и `/usr/bin`. **Перечитать подключения** выполняет только локальную команду `kubectl config get-contexts --output=name`. Списки namespace и подов загружаются из выбранного кластера при открытии виджета и смене окружения; кнопки **Обновить namespace** и **Обновить поды** повторяют соответствующий запрос. Фонового опроса нет. Используются текущие доступы kubectl, включая настроенные плагины авторизации; при необходимости войдите через терминал и повторите запрос. Запросы ограничены по времени. При ошибках доступа, сети и авторизации показывается сообщение; старые поды другого окружения не отображаются.

Используется `KUBECONFIG`, унаследованный процессом OxDeck, либо стандартный `~/.kube/config`. Переменная, заданная только в настройках shell, может быть недоступна при запуске из Finder. Если нет прав на список namespace, можно ввести известный namespace вручную и загрузить его поды. Ручной ввод pod и контейнера также доступен; имя service для port-forward вводится вручную.

## Переписать текст

Добавьте плитку через **Изменить → пустая клетка → Переписать текст → Сохранить**. Скопируйте письмо или сообщение и нажмите плитку. Codex исправит ошибки и неуклюжие формулировки, сохранив язык, тон, смысл и абзацы. В буфер попадёт только готовый текст. Инструкция фиксированная.

Во время обработки плитка показывает индикатор загрузки и не принимает повторные запуски. Готовый результат всегда заменяет буфер, даже если за время ожидания вы скопировали что-то другое. При пустом буфере, ошибке или пустом ответе буфер не меняется. Поддерживается обычный текст до 100 КБ, оформление из текстовых редакторов не сохраняется. Ожидание ответа ограничено двумя минутами.

Нужен установленный и авторизованный Codex CLI (`codex login`). Используются текущая модель и авторизация CLI; текст обрабатывается выбранным в Codex провайдером. OxDeck ищет `codex` в PATH, `/opt/homebrew/bin`, `/usr/local/bin`, `~/.local/bin` и внутри приложений ChatGPT/Codex в `/Applications`.

Для каждого запуска OxDeck получает список MCP-серверов через `codex mcp list --json` и передаёт `-c mcp_servers.<имя>.enabled=false` для каждого сервера. Подключения из приложений и плагинов также отключаются параметрами запуска. Пользовательский конфиг не меняется. Используется `codex exec --ephemeral` в отдельной временной папке: проектные инструкции не загружаются, файл истории сессии не сохраняется. Содержимое буфера передаётся через stdin.

## Проверка и сборка

```bash
pnpm check
pnpm start
pnpm package
```

Весь JavaScript приложения и инструментов написан на TypeScript. Electron main/preload находятся в `electron`, интерфейс — в `src`, общая логика сетки — в `shared`, нативное управление окнами — в `native`.

Готовое приложение появляется в `out/OxDeck-darwin-*`. Сборка пока не подписана сертификатом Apple.
